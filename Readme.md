# Portfolio Showcase & Catalog

A sleek, responsive portfolio showcase and service catalog web application featuring a stunning **frosted-glass (glassmorphism)** aesthetic, interactive pricing packages, customizable add-ons, and secure admin management.

## 🚀 Features

* **Frosted Glass UI**: Modern translucent glassmorphic design with deep background gradients and smooth blur effects.
* **Portfolio Packages**: Dynamic catalog showcasing services like Full-Stack Development, Software Engineering, UI/UX Design, and more with sample image previews.
* **Add-ons & Extras**: Clean list layout displaying auxiliary services and upgrades.
* **Admin Panel**: Password-protected backend mode allowing admins to **Add, Edit, and Delete** portfolio packages and add-ons directly from the browser.
* **Instant WhatsApp Inquiries**: Client booking forms that automatically format and forward inquiries directly to WhatsApp.
* **Direct Contact Hub**: Quick-access links for Email, Phone/WhatsApp, GitHub, Instagram, and LinkedIn.
* **Persistent Storage**: Utilizes browser `localStorage` and `sessionStorage` to save catalog modifications.

---

## 🛠️ Tech Stack

* **HTML5** & **CSS3** (Flexbox, Grid, Backdrop Filters)
* **Vanilla JavaScript** (DOM manipulation, LocalStorage API)
* **Google Fonts** (Plus Jakarta Sans)
